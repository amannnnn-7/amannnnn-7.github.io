evaluating compositional reasoning in LLMs

June 2025 - July 2025 with Prof. Pankaj Pansari

Research project investigating whether large language models genuinely understand recursive problem-solving and compositional generalization, or simply memorize templates from training data. Using Scheme as a controlled evaluation medium, this work probes the limits of LLM reasoning capabilities.

key contributions:

  • Designed experimental pipeline to evaluate LLM code generation on competitive programming problems from DeepMind Code Contests dataset
  • Developed novel modified Scheme methodology: replaced all Scheme primitives (map, cons, filter) with arbitrary tokens to eliminate memorization
  • Built sandboxed interpreter-based evaluation system in Python for safe execution of untrusted LLM-generated code
  • Conducted cross-language comparison study between Python (81% pass@5) and Scheme (62% pass@5) to isolate language familiarity effects
  • Demonstrated that removing lexical cues caused approx. 16% performance drop, with scaffolding providing minimal recovery (46% → 48%)
  • Findings reveal fundamental limitations in current LLMs' ability to perform true compositional reasoning versus surface pattern matching

technologies:

Python, Scheme, Anthropic APIs, Subprocess Sandboxing, AST Parsing, Code Synthesis Evaluation

baba is RL

January 2025 - May 2025 with Prof. Sandeep Manjanna

Training reinforcement learning agents to play the puzzle game "Baba is You", which features complex rule-based mechanics and requires abstract reasoning. This project explores how different RL architectures handle dynamic game rules and compositional reasoning.

key contributions:

  • Devised training levels, environment pipeline for training RL models on Baba is You
  • Proposed, engineered and tested a range of models including DQN, PPO and Hierarchical RL
  • Implemented custom reward shaping to encourage exploration and rule understanding

technologies:

Python, PyTorch, OpenAI Gym, Reinforcement Learning

canDTI - Drug Target Interaction Prediction

January 2024 - May 2024 with Prof. Siddharth

Research project focused on predicting drug-target binding affinity using deep learning. This work aims to accelerate drug discovery by computationally identifying promising drug candidates for specific protein targets.

key contributions:

  • Performed research and literature review for current ML trends in drug target interaction
  • Developed and completed CNN encoding, preprocessing tools for drug-target sequence data
  • Proposed and developed CNN-RNN hybrid model for prediction of binding affinity values
  • Achieved competitive performance on benchmark DTI datasets

technologies:

Python, TensorFlow, BioPython, CNN, RNN, Sequence Analysis
